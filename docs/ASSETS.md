# Crownless — Asset Provenance

_GDD §11–§12 art bible ("No real Pokémon sprites, tiles, trademarks, or assets") and §14 Gate E ("original/licensed art"). Last reviewed 2026-11-17, build 0.34.0._

**In one line:** everything the game ships is either sprite art the project owner made with AI (through their own tool, Sprite Studio) or is generated in code. There is no third-party art, sound, music, font or runtime library.

| **Sound effects and music** (14 effects, 3 loops) | none | Synthesized live with the Web Audio API in `js/audio.js` | Code, written for this project |
| **Text** (story, dialogue, quests, help, news) | `data/*.js` | Written for this project | Project owner |
| **Font** | none shipped | The device's own Georgia (serif fallback) and system UI fonts | Not distributed |
| **Page icon** | inline in `index.html` | The ⚔️ emoji, drawn by the device's emoji font | Not distributed |

`assets/manifest.json` lists every image file with its source and whether the game uses it. It's rebuilt by `node scripts/asset-manifest.js`, and `tests/assets.test.js` fails if a file in `assets/` is missing from it, if its "used" flags are out of date, or if the game asks for a file that isn't there.

**Unused files:** 84 of the 169 images are never loaded by the game. All are unit frames: other characters and animation poses from the same sheets. The owner chose to keep them in the repository, and they are marked `"used": false` in the manifest. They are published with the site, about 0.5 MB, but never downloaded by players, since the game only requests what it uses.

**Runtime dependencies:** none. The page loads only its own files: no CDN, web fonts, analytics or trackers. Development tools (`@biomejs/biome` for lint, `http-server` for local serving) run through `npx` on the developer's machine and are not shipped.

## Things to keep in mind (not legal advice)
- **AI-generated images.** The sheets were generated with **ChatGPT**'s image tools (OpenAI). How copyright applies to AI-generated images depends on the country, and OpenAI's terms of use govern the outputs. Before selling, read the then-current terms on ownership and commercial use of outputs and keep a dated copy with the release records (`docs/V2-PLAN.md` R-01).
- **The GDD's "no Pokémon" rule.** The sprites are a generic 16-bit fantasy style: hooded wanderers, helmeted soldiers, tabards and pennants. None of them are characters, tiles or logos from an existing game. The rule is about copying; a similar era look is fine.
- **Adding art later:** put files in `assets/`, run `node scripts/asset-manifest.js`, and set the `source` of any file that didn't come from Sprite Studio. Add that source under `sources` with its origin and licence (for example a CC0 pack, with its link).
