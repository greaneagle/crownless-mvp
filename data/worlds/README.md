# Other official worlds

A world package here (`<id>.js`, in the world format of `docs/WORLD-FORMAT.md`) would ship as a second official world beside the Sundered Realm: `js/worlds.js` lists it, and a new game asks which world to play.

There are none now. The Sundered Coast, the second world from 3.14.0, became the Sundered Realm's far east in 4.2.0 (P10-02): the owner wants one sandbox world, not two split games. The loader stays, for packs and for any later world.
